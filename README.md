# lili pensa demais

Site pessoal e literário, gerado com Jekyll e publicado no GitHub Pages.
O conteúdo (poemas e pensamentos) é publicado e editado pelo painel administrativo em `/admin` — não é necessário editar código para publicar.

- Estrutura do site: `_layouts`, `_includes`, `assets/`
- Conteúdo: `_poemas/`, `_pensamentos/`, `about/index.html`, `_data/settings.yml`
- Painel administrativo: `admin/` (Decap CMS)
- Publicação automática: `.github/workflows/jekyll.yml`
